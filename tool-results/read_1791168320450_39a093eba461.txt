     1→     1→     1→# SedimentCarbon dMRV - Worklog
     2→     2→     2→
     3→     3→     3→## Project Overview
     4→     4→     4→Building a Digital MRV (Measurement, Reporting, Verification) system for
     5→     5→     5→Sediment-Trap Agriculture Carbon Projects. Adapted from a Python FastAPI +
     6→     6→     6→PostgreSQL architecture (PDF spec) to Next.js 16 + TypeScript + Prisma (SQLite)
     7→     7→     7→+ shadcn/ui, with bilingual UI (TH/EN) and all calculation engines ported to
     8→     8→     8→TypeScript.
     9→     9→     9→
    10→    10→    10→## Architecture decisions
    11→    11→    11→- Single SPA on `/` route (per project rules), internal tab/section navigation.
    12→    12→    12→- API routes under `/api/*` (Next.js Route Handlers).
    13→    13→    13→- Core engines as pure TypeScript modules under `src/lib/core/`.
    14→    14→    14→- Prisma + SQLite for persistence (PostGIS geospatial replaced with GeoJSON
    15→    15→    15→  strings + client-side rendering).
    16→    16→    16→- i18n via custom lightweight context (TH/EN), no external runtime needed.
    17→    17→    17→- Hash chain audit trail stored alongside each soil sample record.
